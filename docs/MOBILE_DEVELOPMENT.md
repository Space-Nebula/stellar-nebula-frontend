# Mobile Development Guide

## Testing Setup

- Test on real devices (iOS and Android) whenever possible.
- Use simulators for rapid iteration.

## Touch Gesture Patterns

- Follow native platform guidelines for swipes, long-presses, and pinches.
- Ensure tap targets are at least 44x44 points.

## Performance Targets

- Target 60fps for all animations and scrolling.
- Keep bundle sizes minimal for fast loading on 3G networks.

## Responsive Design Guidelines

- Use flexible grids and media queries.
- Optimize images for different screen densities (1x, 2x, 3x).
