# 4. Vite Build Tooling and Module Bundling

- Status: Accepted
- Deciders: Frontend Engineering Team
- Date: 2026-08-29

## Context and Problem Statement

Fast development HMR (Hot Module Replacement) and optimized production asset bundling are required for the TypeScript and React frontend.

## Decision Outcome

Chosen option: "Vite", due to instant server start with ESM, fast Rollup-based production builds, and native PWA/Storybook integration support.
