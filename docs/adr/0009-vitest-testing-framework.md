# 9. Vitest for Automated Unit and Component Testing

- Status: Accepted
- Deciders: QA & Frontend Team
- Date: 2026-08-29

## Context and Problem Statement

Selecting a fast test runner compatible with Vite ES module resolution and HappyDOM environment.

## Decision Outcome

Chosen option: `vitest` due to instant native Vite config sharing, fast parallel worker execution, and coverage provider integration.
