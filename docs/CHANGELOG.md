# Changelog

The canonical, versioned changelog for this project lives at the repository root: **[../CHANGELOG.md](../CHANGELOG.md)**.

It follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) conventions and [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- Changes are grouped under `Added`, `Changed`, `Fixed`, `Deprecated`, `Removed`, and `Security`.
- An `[Unreleased]` section at the top tracks changes that haven't shipped in a tagged release yet.
- Entries reference the GitHub issue/PR number that introduced them where relevant.

This file exists only as a pointer so the changelog is discoverable from `docs/` — please add new entries to the root `CHANGELOG.md`, not here, to avoid two changelogs drifting out of sync.
